## Quick Reference: What Changed in 2026

### 1. INP Replaced FID (March 2026)
**Old Metric:** FID (First Input Delay) - measured delay until first interaction
**New Metric:** INP (Interaction to Next Paint) - measures ALL interactions throughout page visit
**Why It Matters:** More comprehensive responsiveness metric
**Your Action:** Monitor in Google Search Console Core Web Vitals report

### 2. AI Search Is Mainstream
**The Shift:** ChatGPT, Claude, Perplexity are now primary research tools
**Impact:** They cite sources when answering health questions
**Your Action:** Optimize to be cited by AI engines

**What AI Engines Look For:**
- Direct, scannable answers (TL;DR summaries) ✅ you have these
- Structured content (FAQs, tables, lists) ✅ you have these
- Freshness signals ("Last Reviewed: 2026") ✅ you have these
- Clear expertise (credentials, schema markup) ✅ you have these
- Local signals (city/state mentions, address) ✅ you have these

### 3. Brand Signals Are Ranking Factors
**The Shift:** Google values brand mentions, reviews, citations across the web
**Impact:** Directory listings matter more than ever
**Your Action:** Build consistent presence across directories

### 4. Google Business Profile Is Essential
**The Shift:** GBP is primary source for local business info
**Impact:** Affects local pack rankings, AI citations, Google Maps
**Your Status:** ✅ Already set up
**Your Action:** Keep updated, collect reviews, add posts monthly

## Common Mistakes to Avoid

### ❌ DON'T:
1. **Inconsistent NAP** - Use exact same name/address/phone everywhere
2. **Ignore AI search** - It's not the future, it's now
3. **Neglect reviews** - They're ranking factors
4. **Pay for sketchy directories** - Stick to proven ones
5. **Ignore Core Web Vitals** - Google uses them for rankings
6. **Forget mobile** - 70%+ of therapy searches are mobile
7. **Skip monthly monitoring** - SEO requires ongoing attention

### ✅ DO:
1. **Test AI visibility monthly** - ChatGPT, Claude, Perplexity
2. **Monitor Core Web Vitals** - Google Search Console
3. **Request reviews systematically** - But naturally, not forced
4. **Keep content fresh** - Update dates, add current info
5. **Build directory presence** - Start with Psychology Today
6. **Track everything** - Can't improve what you don't measure
7. **Focus on mobile** - Test on real phones, not just desktop
