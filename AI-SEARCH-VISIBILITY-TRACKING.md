## How to Test

### ChatGPT (chat.openai.com)
**Test Query Format:**
- "What's the best [service] in [location]?"
- "Who provides [service] in [location]?"
- "I need [service] in [location], what are my options?"

**Example:**
```
"I need ADHD testing in Dearborn, Michigan. What are my options?"
```

### Claude (claude.ai)
**Test Query Format:**
- "Who provides [service] in [location]?"
- "Find me a therapist for [condition] in [location]"

**Example:**
```
"Who provides autism evaluation in Dearborn, Michigan?"
```

### Perplexity (perplexity.ai)
**Test Query Format:**
- "[Service] [location]"
- "Best [service] in [location]"

**Example:**
```
"Autism evaluation Dearborn Michigan"
```

## Content Optimization for AI Citation

### What AI Engines Look For:

1. **Direct Answers**
   - TL;DR summaries ✅ (already have)
   - Clear "What is it?" sections
   - "How we help" explanations

2. **Structured Information**
   - FAQ sections
   - Lists and tables
   - Statistics with sources
   - Last Reviewed dates ✅ (already have)

3. **Local Signals**
   - City/state mentions (Dearborn, Michigan)
   - Address in schema ✅ (already have)
   - Phone number visible
   - Service area mentions

4. **Authority Signals**
   - Therapist credentials
   - Insurance accepted
   - Years in practice
   - Specializations

## Optimization Tactics

### If Not Being Cited:

1. **Add More Structured Content**
   - FAQ section specific to that service
   - Statistics about the condition
   - Table of treatment options
   - Clear pricing/insurance info

2. **Strengthen Local Signals**
   - Mention "Dearborn, Michigan" more frequently
   - Add neighboring cities (Detroit, Ann Arbor, Troy)
   - Include "serving" statements

3. **Update Freshness Signals**
   - Update "Last Reviewed" dates monthly
   - Add current year to content (2026)
   - Reference recent research/guidelines

4. **Improve Answer-Ability**
   - Make content more scannable
   - Use question-based headings
   - Put key info in first 200 words
